# Overhead album country variants

Created using the built-in image generation tool. The Italy overhead photograph is the shared edit target; each country's flat cover is the artwork reference. The landing page selects one of these photographs or Italy at random on each server page request. The selected image stays fixed during the visit and moves subtly with scroll; reduced-motion preferences disable the parallax. There are no slideshow controls or automatic image changes.
