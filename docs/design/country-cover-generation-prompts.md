# Country cover generation prompts

Generated with the built-in image generation tool, using the existing Italy, Tokyo, and Rome covers as visual references. Original outputs are preserved; production copies are in `public/images/landing/covers/` at 1024 × 1536 pixels.

Italy and Vietnam reuse the original artwork documented in [travel-cover-prompts.md](./travel-cover-prompts.md).

## France

Asset: `public/images/landing/covers/france.png`

```text
Use case: illustration-story. Create one finished travel photo album cover artwork in the exact same coordinated series as the three attached reference covers (Italy, Tokyo, Rome). Portrait 2:3, 1024x1536, crisp print-quality edges. Same artist, same typography, same layout.
Country: France. Midnight French blue background, warm ivory title and golden year. Large elegant Eiffel Tower in warm gold and cream, graceful precise ironwork and confident silhouette, no surrounding city.
Exact printed text: "FRANCE" and "2025". Set country name in ONE LINE of enormous, extra-heavy condensed uppercase block lettering across the top with 5% side margins, beginning at 3% height and ending at 23% height. Condense long names so all letters fit. Small bold year directly underneath at the right, baseline at 29% height. Main illustration fills the lower two thirds, from approximately 34% to 94% height. Use sophisticated mid-century gouache / flat screenprint shapes, clean organic silhouettes, restrained 5-color palette, flat shaded details, same level of refinement as the reference lemon and Colosseum illustrations.
Output ONLY the flat rectangular printed artwork edge to edge: no actual book, no spine, no mockup, no rotation, no perspective distortion of the page, no margin around the artwork, no border, no shadow, no fabric backdrop, no extra words, no watermark. No blurry or pixelated edges, no coarse noise overlay, no photographic rendering. Match the reference typography and scale very closely.
```
